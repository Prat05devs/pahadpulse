# Frontend — 04 UI & Design System

Tailwind v4 + shadcn/ui + Radix. Tokens in CSS, primitives generated, compositions hand-written.

---

## 1. The token layer

All design decisions are CSS variables in `app/globals.css`. Nothing else defines a colour, a
radius, or a font.

```css
@import 'tailwindcss';
@import 'tw-animate-css';

@custom-variant dark (&:is(.dark *));

@theme inline {
  --color-background: var(--background);
  --color-foreground: var(--foreground);
  --color-primary: var(--primary);
  --color-primary-foreground: var(--primary-foreground);
  --color-secondary: var(--secondary);
  --color-muted: var(--muted);
  --color-muted-foreground: var(--muted-foreground);
  --color-accent: var(--accent);
  --color-destructive: var(--destructive);
  --color-border: var(--border);
  --color-input: var(--input);
  --color-ring: var(--ring);

  --radius-sm: calc(var(--radius) - 4px);
  --radius-md: calc(var(--radius) - 2px);
  --radius-lg: var(--radius);

  --font-sans: var(--font-geist-sans), system-ui, sans-serif;
}

:root {
  --radius: 0.625rem;
  --background: oklch(1 0 0);
  --foreground: oklch(0.145 0 0);
  --primary: oklch(0.51 0.19 259);
  --primary-foreground: oklch(0.985 0 0);
  /* ... */
}

.dark { /* every token redefined */ }
```

### Rules

| # | Rule |
|---|---|
| T1 | **No hardcoded colours in components.** `bg-red-500`, `text-[#1565C0]`, `#fff` are all blocking review comments. Use `bg-destructive`, `text-primary`. |
| T2 | Every token defined in `:root` **must** also be defined in `.dark`. A missing dark token is an invisible-text bug. |
| T3 | Colours in `oklch` — perceptually uniform, so generated shades stay consistent. |
| T4 | Semantic names (`--primary`, `--destructive`, `--muted`), never literal ones (`--blue`, `--red-500`). |
| T5 | Spacing uses Tailwind's scale. Arbitrary values (`mt-[13px]`) require a comment justifying them. |
| T6 | Tailwind v4 configures in CSS. Delete `tailwind.config.js` unless a plugin genuinely requires it. |

> The reference defines `--primary: #1565C0` and `--secondary: #2E7D32` in `:root` but
> overrides them to greyscale in `.dark` — so brand colour disappears in dark mode. Define
> every token in both blocks, deliberately.

## 2. Typography

Defined once, applied through utilities. No per-component font sizes invented ad hoc.

| Role | Classes |
|---|---|
| Page title (h1) | `text-3xl md:text-4xl font-bold tracking-tight` |
| Section title (h2) | `text-2xl font-semibold tracking-tight` |
| Card title (h3) | `text-lg font-semibold` |
| Body | `text-base leading-relaxed` |
| Small / meta | `text-sm text-muted-foreground` |
| Caption | `text-xs text-muted-foreground` |

Fonts load via `next/font` with `display: 'swap'`, self-hosted, exposed as a CSS variable and
wired into `--font-sans`. Never a `<link>` to Google Fonts (layout shift + a third-party
request on the critical path).

Exactly **one** heading level 1 per page, and heading levels never skip.

## 3. Component tiers

```
components/ui/*          shadcn primitives  — GENERATED
components/molecules/*   shared compositions — hand-written, presentational
features/*/components/*  domain UI           — hand-written
```

### `components/ui/` — generated primitives

```bash
npx shadcn@latest add button dialog select
```

| # | Rule |
|---|---|
| U1 | Generated by the CLI. Do not hand-write a file here. |
| U2 | Edit **only** to change project-wide styling (variants, default sizes). Never to add business logic. |
| U3 | Never import a feature type or a hook into `components/ui/`. |
| U4 | Keep the shadcn API — `variant`, `size`, `asChild`. Don't invent a different prop vocabulary. |
| U5 | Every primitive has a story with all variants and sizes. |

### Variants with `cva`

```tsx
const buttonVariants = cva(
  'inline-flex items-center justify-center gap-2 rounded-md text-sm font-medium transition-colors ' +
  'focus-visible:ring-ring/50 focus-visible:ring-[3px] focus-visible:outline-none ' +
  'disabled:pointer-events-none disabled:opacity-50',
  {
    variants: {
      variant: {
        default: 'bg-primary text-primary-foreground hover:bg-primary/90',
        destructive: 'bg-destructive text-white hover:bg-destructive/90',
        outline: 'border bg-background hover:bg-accent hover:text-accent-foreground',
        ghost: 'hover:bg-accent hover:text-accent-foreground',
        link: 'text-primary underline-offset-4 hover:underline',
      },
      size: { sm: 'h-8 px-3', default: 'h-9 px-4 py-2', lg: 'h-10 px-6', icon: 'size-9' },
    },
    defaultVariants: { variant: 'default', size: 'default' },
  },
);
```

New visual states become **variants**, never one-off `className` overrides scattered across
call sites.

## 4. `cn()` and class ordering

```ts
// lib/utils.ts
export function cn(...inputs: ClassValue[]): string {
  return twMerge(clsx(inputs));
}
```

Always merge incoming `className` **last** so callers can override:

```tsx
<div className={cn('flex items-center gap-2', isActive && 'bg-accent', className)} />
```

`prettier-plugin-tailwindcss` sorts classes automatically — never argue about order.

**Never** build class strings by concatenation (`'text-' + colour`) — Tailwind's scanner can't
see them and they get purged.

## 5. Responsive design

Mobile-first. Unprefixed styles are the mobile styles.

```tsx
<div className="grid grid-cols-1 gap-4 md:grid-cols-2 lg:grid-cols-3 xl:gap-6">
```

| Breakpoint | Min width | Target |
|---|---|---|
| (none) | 0 | phone |
| `sm` | 640 | large phone |
| `md` | 768 | tablet |
| `lg` | 1024 | laptop |
| `xl` | 1280 | desktop |
| `2xl` | 1536 | large desktop |

Rules: design at 375px first; content max width `max-w-7xl mx-auto px-4 md:px-8`; touch
targets ≥ 44×44 px; never `hidden md:block` to render two copies of the same content — it
doubles the DOM and breaks screen readers.

Use container queries (`@container`) when a component's layout should respond to its slot
rather than the viewport.

## 6. Layout primitives

| Need | Use |
|---|---|
| One-dimensional row/column | `flex` |
| Two-dimensional grid | `grid grid-cols-*` |
| Consistent gaps | `gap-*`, never margins between siblings |
| Page shell | `mx-auto w-full max-w-7xl px-4 md:px-8` |
| Vertical rhythm | `space-y-*` on the container |
| Sticky header | `sticky top-0 z-40 bg-background/80 backdrop-blur` |

`z-index` values come from a fixed scale — `z-10` content, `z-20` sticky, `z-40` header,
`z-50` overlays/dialogs. Never invent `z-[9999]`.

## 7. Interaction states

Every interactive element defines all five:

```tsx
'transition-colors hover:bg-accent ' +
'focus-visible:ring-ring/50 focus-visible:ring-[3px] focus-visible:outline-none ' +
'active:scale-[0.98] ' +
'disabled:pointer-events-none disabled:opacity-50 ' +
'aria-[current=page]:bg-accent'
```

**Never remove the focus ring.** `outline: none` without a `focus-visible` replacement makes
the app unusable by keyboard, and is a blocking review comment.

---

## 8. Loading, empty, and error UI

| State | Component |
|---|---|
| Loading | `<Skeleton />` matching the real layout's dimensions |
| Empty | `<EmptyState icon title description action />` |
| Error | `<ErrorState error onRetry />` |
| Inline pending | Button `disabled` + spinner, label changes to "Saving…" |

Skeletons must match the final layout's box sizes — a skeleton of the wrong height causes CLS,
which is worse than a spinner. Never use a bare centred spinner for a page load.

## 9. Images

```tsx
<Image
  src={article.image}
  alt={article.title}          // "" only if truly decorative
  width={800}
  height={450}
  sizes="(max-width: 768px) 100vw, (max-width: 1200px) 50vw, 33vw"
  priority={isAboveFold}
  className="rounded-md object-cover"
/>
```

Rules: always `next/image`; always explicit `width`/`height` or `fill` with a sized parent;
always `sizes` for responsive images; `priority` on the LCP image only; configure hosts with
`images.remotePatterns` (not the deprecated `images.domains`); meaningful `alt`, or `alt=""`
for decoration.

## 10. Icons and motion

- Icons: `lucide-react` only. Size with `className="size-4"`, colour with `text-*`. Decorative
  icons get `aria-hidden="true"`; icon-only buttons get an `aria-label`.
- Motion: CSS transitions for 90% of cases. Durations 150–300 ms, `ease-out` for enter,
  `ease-in` for exit. Animate only `transform` and `opacity`.
- Always respect `prefers-reduced-motion`:

  ```css
  @media (prefers-reduced-motion: reduce) {
    *, *::before, *::after { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; }
  }
  ```

- [ ] Every `:root` token has a `.dark` counterpart.
- [ ] Primitives generated by shadcn, unedited except for styling.
- [ ] New visual states are `cva` variants, not one-off classNames.
- [ ] `className` merged last with `cn()`.
- [ ] Mobile-first; verified at 375 / 768 / 1440.
- [ ] Touch targets ≥ 44 px.
- [ ] Focus-visible ring present on every interactive element.
- [ ] Loading skeletons match final layout dimensions.
- [ ] Images use `next/image` with `sizes`; LCP image has `priority`.

- [ ] Every exported component has a story.
